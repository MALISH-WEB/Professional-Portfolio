**Portfolio Website README**
This README provides an overview of my personal IT student portfolio website. The website showcases my projects, skills, and achievements as an aspiring Information Technology professional.
Live URL: https://malish-web.github.io/Professional-Portfolio/

**1. Website Overview**
The portfolio website serves as a digital representation of my learning journey, highlighting my academic and personal projects. It includes information about me, my skills, educational background, and links to my professional profiles.

**2. Key Features**
• Home section with a brief introduction and tagline.
• About section summarizing my IT background and career goals.
• Projects section showcasing academic and personal works with descriptions and images.
• Contact section with a working contact form or contact details.
• Social media links (GitHub, LinkedIn, Twitter) for networking and collaboration.

**3. Technologies Used**
• HTML5 – for structuring web pages.
• CSS3 – for styling and layout design.
• Bootstrap – for customizable html and css
• GitHub Pages / Netlify – for hosting and deployment.
